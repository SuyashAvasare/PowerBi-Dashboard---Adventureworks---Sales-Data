AdventureSales (AdventureWorks Sales) is a sample retail dataset that contains transactional sales records, customers, products, and territories for a fictional bicycle and accessories company. It is typically used to learn and demonstrate skills in data modeling, visualization, and analytics.
​

Dataset overview
The data represents an omni-channel business that sells bikes and related products through internet and reseller channels across multiple countries and regions.
​

It usually includes several related tables such as sales orders, customers, products, resellers, calendar/date, and sales territories, making it well suited for star-schema modeling.
​

Core tables and fields
Sales tables typically include order date, ship date, customer key, product key, territory key, order quantity, unit price, discount, cost, and sales amount.
​

Dimension tables describe customers (demographics), products (category, subcategory, model, list price), territories (country, region, group), resellers, and calendar attributes (year, quarter, month).
​

Typical use cases
Building interactive dashboards to track total sales, profit, order volume, and average order value by time, product category, channel, and region.
​

Practicing data preparation tasks such as cleaning, joining tables, creating calculated measures, and designing KPIs for sales performance analysis.
​​

File formats and sources
AdventureSales data is available as SQL databases, Excel/CSV files, and BI sample files (such as Power BI PBIX) provided by Microsoft and the data community.
​

It is free to download and is widely used in tutorials, courses, and portfolio projects for learning analytics and business intelligence.
